# Linux Admin Toolkit
A Bash application developed during Linux classes to practice Shell Script and Linux system administration.

![Demo] (assets/demo.gi)

## 🇺🇸 English

### About

This project was developed as part of a Linux course assignment.

The instructor provided the initial project framework, including the application's startup information. Based on this framework, I designed and implemented the interactive menu and developed the required features by researching Bash commands and Linux utilities.

The user verification feature was implemented using logic shared by another student and adapted for this project. The directory verification feature was developed by extending and modifying that implementation.

### Features

- Interactive menu
- System information
- System status
- Open external links
- User verification
- Directory verification

### Technologies

- Bash
- Shell Script
- Linux

### Credits

- Initial framework provided by the course instructor.
- Interactive menu, system information, system status, and link-opening features developed by me.
- User verification based on logic shared by another student and adapted for this project.
- Directory verification developed by me based on the user verification feature.

## 🇧🇷 Português

### Sobre

Este projeto foi desenvolvido como parte de uma atividade da disciplina de Linux.

O professor disponibilizou um framework inicial contendo apenas a estrutura da aplicação e as informações exibidas na inicialização. A partir dessa base, desenvolvi o menu interativo e implementei as funcionalidades propostas na atividade, pesquisando comandos do Bash e recursos do Linux.

A funcionalidade de verificação de usuários foi implementada com base na lógica compartilhada por outro aluno e adaptada para este projeto. A verificação de diretórios foi desenvolvida por mim utilizando essa funcionalidade como referência e realizando as adaptações necessárias.

- Menu interativo
- Informações do sistema
- Status do sistema
- Abertura de links
- Verificação de usuários
- Verificação de diretórios

### Tecnologias

- Shell Script
- Linux

- Verificação de diretórios desenvolvida por mim com base na implementação da verificação de usuários.
